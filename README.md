# Arduino-Based Traffic Control System

## Project Description
This project is an automatic traffic light control system using Arduino Uno.

It controls Red, Yellow and Green LEDs to simulate traffic signals.

## Components Used
- Arduino Uno
- Red LED
- Yellow LED
- Green LED
- Breadboard
- 220 Ohm Resistors
- Connecting Wires

## Connections
- Red LED - Pin 2
- Yellow LED - Pin 3
- Green LED - Pin 4
- Common GND

## Working Principle
The Arduino controls three LEDs automatically.

1. Red LED turns ON.
2. Green LED turns ON.
3. Yellow LED turns ON.
4. The sequence repeats continuously.
